    After you save: deploy it

    Run these in a terminal, in this project folder. A second terminal is fine, or stop this page first with Ctrl+C.

    2. Prepare your account for CDK (once per account and region)
      npx cdk bootstrap
    3. Deploy

      Runs the safety checks first and stops with a clear message if anything is off.

      npm run deploy
    4. Confirm your email

      AWS sends a "Subscription Confirmation" email. Click the link in it, or no alerts arrive.

    5. Check that the email is confirmed

      Use the ReportTopicArn printed at the end of the deploy.

      npm run verify -- <ReportTopicArn>
